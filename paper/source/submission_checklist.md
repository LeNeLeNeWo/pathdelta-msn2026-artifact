# MSN 2026 submission checklist

Checked on 2026-08-14 (Asia/Shanghai).

- [x] Official MSN 2026 template downloaded and SHA-256 recorded.
- [x] IEEEtran conference mode reports 10-point, double-column, US Letter.
- [x] Eight pages total, including references (limit: eight).
- [x] Anonymous author block; no acknowledgments or funding footnote.
- [x] Extracted-text scan contains no project author names, affiliations,
  emails, WSL paths, or private repository paths.
- [x] No unresolved citations/references, overfull boxes, or fatal LaTeX errors.
- [x] All PDF fonts are embedded.
- [x] PDF is not encrypted and contains no forms or JavaScript.
- [x] Every final page rendered to PNG and visually inspected; figures and
  tables fit without clipping or overlap.
- [x] Main boundary results trace to frozen v8.3 external artifacts; no legacy
  pre-v8.3 experimental data or benchmark aggregate is used.
- [x] The observed 10-point reduction is reported as below the preregistered
  15-point effect-size threshold; no preregistered magnitude is claimed.
- [x] Zero registered false accepts is accompanied by Wilson bounds, an
  independent Batfish model-gap audit, and an explicit non-universality claim.
- [x] Original Agent128, post-freeze development replay, disjoint holdout,
  independent Batfish audit, and adaptive union repair are explicitly separated.
- [x] Agent results report safety, repair, fail-closed N/A, calls, backend
  attempts, retries, tokens, latency, and the archived transport incident.
- [x] Source package excludes build files, virtual environments, review notes,
  old papers, experiment data, identities, and credentials.
- [x] The packaged source compiles in a fresh temporary directory.

The PDF can be uploaded to the MSN 2026 Regular Paper submission site after the
authors enter title, abstract, keywords, conflicts, and author metadata in the
submission form itself.
